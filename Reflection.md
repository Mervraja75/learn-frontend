# Reflection

## What did you ask the AI to do?
I collaborated with the AI over five weeks to develop a React Native frontend connected to a real REST API backend. Together we worked on setting up the project with Expo, building core components, setting up React Navigation, implementing a login and signup flow with JWT token storage using expo-secure-store, creating an AuthContext for global state management, and building out the clients screens — view all, view one, create, update, and delete. For the final project, we also built out the tickets section with view all, view one, and create screens, added a profile tab showing the logged in user's information, and connected everything to a real MongoDB database running locally via OrbStack.

## What did it do well?
The AI was really good at explaining concepts in simple terms whenever I didn't understand something. It always gave me full updated files instead of just showing me the changed lines, which made it easier to follow along. It was also good at breaking things down step by step — we built one thing at a time and made sure it worked before moving on. When errors came up it was quick at helping me diagnose the problem, like when the iOS simulator timed out, when the token wasn't being shared across screens, or when the backend was crashing because some clients had missing user_id fields.

## What did it get wrong or what did you have to fix?
A few things needed fixing along the way. The AuthContext wasn't being used correctly at first — the LoginScreen was saving the token directly to SecureStore instead of going through AuthContext, which meant the token wasn't available to other screens. The AuthProvider was also placed inside AppNavigator instead of at the root level, which caused the Profile tab to not have access to the user's token. The backend also had a bug where clients created without a user_id were causing 500 errors on update and delete — we fixed that by adding a null check before calling toString(). These weren't things the AI got completely wrong, but they required some back and forth to figure out.

## What did I learn from working with it?
I learned that AI is most useful when you understand what you're building well enough to ask the right questions. When I just copied code without reading it I got confused later when something broke. But when I collaborated with the AI to understand why something worked — like how AuthContext shares state across screens, or how JWT tokens are attached to API requests — it actually helped me understand React Native much better. I also learned that AI doesn't always get things right on the first try, and being able to read the code and spot the problem is just as important as knowing how to ask for help.
